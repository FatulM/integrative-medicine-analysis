# دعوای طب سنتی و پزشکی جدید: نگاهی ساده به علم و جامعه

## 📖 درباره پروژه

این پروژه یک وب‌سایت ایستا (static) است که به تحلیل دعوای بزرگ بین **طب سنتی** و **پزشکی جدید** در ایران می‌پردازد. هدف این سایت ارائه یک بحث علمی و عاقلانه درباره تفاوت‌ها و تشابه‌های این دو نگاه متفاوت به سلامت است.

## 🎯 هدف

این وب‌سایت برای:
- تشریح تفاوت میان **طب سنتی دانشگاهی** و **ادعاهای دروغین** است
- نشان دادن اینکه چگونه علم می‌تواند اسرار طب سنتی را کشف کند
- بحث درباره مشکلات واقعی دو سیستم درمانی
- ارائه نگاهی متوازن و عاقلانه برای خوانندگان ایرانی

## 📁 ساختار پروژه

```
integrative-medicine-analysis/
├── index.html           # وب‌سایت (شامل HTML/CSS/JavaScript)

```

## 🌐 چگونه از سایت استفاده کنیم

### مشاهده آنلاین
فایل `index.html` را در یک مرورگر وب باز کنید. سایت کاملاً ایستا است و نیازی به سرور یا نصب نرم‌افزاری ندارد.

```bash
# یا می‌توانید یک سرور محلی راه‌اندازی کنید:
python3 -m http.server 8000
# سپس به http://localhost:8000 بروید
```

## 📝 محتوای سایت

سایت شامل ۸ بخش اصلی است:

1. **مقدمه**: تعریف دعوای دو نگاه متفاوت به سلامت
2. **تفاوت مفاهیم**: توضیح تفاوت طب عربی، طب سنتی و طب مذهبی
3. **مشکل آزمایش داروها**: چرا اثرات روانی و اجتماعی نادیده گرفته می‌شود
4. **داروهای جدید**: آیا پزشکی جدید همیشه راه‌حل معجزه‌ای دارد؟
5. **دو روی سکه در ایران**: تفاوت طب سنتی دانشگاهی و مدعیان دروغین
6. **طب سوزنی**: مثال آشتی علم و سنت
7. **طبی‌سازی**: چگونه تفاوت‌های طبیعی زندگی به بیماری تبدیل می‌شود
8. **نتیجه‌گیری**: رویکرد عاقلانه به سلامت

برای دیدن محتوای کامل، به فایل `content.md` مراجعه کنید.
