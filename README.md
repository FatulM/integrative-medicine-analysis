# دعوای طب سنتی و پزشکی جدید: نگاهی ساده به علم و جامعه

## 📖 درباره پروژه

این پروژه یک وب‌سایت ایستا (static) است که به تحلیل دعوای بزرگ بین **طب سنتی** و **پزشکی جدید** در ایران می‌پردازد. هدف این سایت ارائه یک بحث علمی و عاقلانه درباره تفاوت‌ها و تشابه‌های این دو نگاه متفاوت به سلامت است.

## 🎯 هدف

این وب‌سایت برای:
- تشریح تفاوت میان **طب سنتی دانشگاهی** و **ادعاهای دروغین** است
- نشان دادن اینکه چگونه علم می‌تواند اسرار طب سنتی را کشف کند
- بحث درباره مشکلات واقعی دو سیستم درمانی
- ارائه نگاهی متوازن و عاقلانه برای خوانندگان ایرانی

### مشاهده آنلاین
فایل `index.html` را در یک مرورگر وب باز کنید. سایت کاملاً ایستا است و نیازی به سرور یا نصب نرم‌افزاری ندارد.

```bash
# یا می‌توانید یک سرور محلی راه‌اندازی کنید:
python3 -m http.server 8000
# سپس به http://localhost:8000 بروید
```

## 📝 محتوای سایت

سایت شامل ۱۱ بخش اصلی است:

1. **چرا این بحث مهم شده است؟**: اهمیت تصمیم میان طب جدید و طب سنتی در ایران
2. **انواع درمان‌های سنتی و مکمل**: معرفی طب سنتی ایرانی (مزاج‌شناسی)، طب سوزنی، گیاه‌درمانی، بادکش‌درمانی و طب اسلامی ادعایی
3. **شبه‌علم**: ویژگی‌های مدعیانی که حرف‌هایشان ظاهر علمی دارد اما واقعی نیست
4. **مشکل آزمایش داروها**: چرا حس خوبِ بیمار (اثر دارونما) نادیده گرفته می‌شود
5. **طبیعی ≠ بی‌خطر**: نبود نظارت، داروهای تقلبی و اثر تلقین در روش‌های طبیعی
6. **داروهای جدید**: چرا نباید به هر داروی جدیدی زود اعتماد کرد
7. **دو روی سکه در ایران**: تفاوت طب سنتی دانشگاهی و مدعیان دروغین
8. **طب سوزنی**: مثال آشتی علم و سنت با کشف راز بافت‌های پیوندی
9. **طبی‌سازی زندگی**: چگونه اتفاقات طبیعی زندگی به بیماری تبدیل می‌شود
10. **مقایسه روش‌های درمان**: جدول مقایسه‌ای پزشکی جدید، طب سنتی، طب سوزنی و طب اسلامی
11. **نتیجه‌گیری**: رویکرد عاقلانه به سلامتی کل انسان

برای دیدن محتوای کامل، به فایل `content.md` مراجعه کنید.
